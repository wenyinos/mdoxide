## 审查红线

1. 不引入 WebView / Electron / JavaScript 运行时（视频嵌入只保留解析，不做 wry 播放）。
2. 不引入 LSP、拼写检查（ROADMAP 已明确不做）。
3. 保持 MarkText 式标题栏、标签栏和现有设置信息架构，不搬 Ferrite 的 ribbon/settings registry。
4. 保持 `Document` 单一正文所有者与修订号机制，不引入第二份正文副本。
5. 不新增 macOS、MSI/Inno、Flathub、Nix 等平台/分发目标。
6. 新依赖必须单独审批；不接受 `[patch.crates-io]` 的 `vendor/epaint`。
7. 上游代码只作行为与测试参考；每个移植项必须有本分支回归测试，UI 改动需视觉验收。

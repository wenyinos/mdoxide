# M3 手工走查清单

自动化部分由 `cargo test --bin mdoxide test_ime` 覆盖（6 项）：预编辑→提交、选区替换、连续组合、取消/禁用清理，以及 `ui()` 端到端路径的预编辑绘制与候选窗矩形。

以下项目需在 Fedora/KDE + fcitx5 真机确认。

## 环境

- 会话：Wayland（`XDG_SESSION_TYPE=wayland`）
- 输入法：fcitx5 + 中文拼音引擎
- 打开 `test_md/test_ime_input.md` 与 `test_md/test_chinese.md`

## IME

1. 组合期间按 Backspace 只删除拼音，不删除正文（Test 1/2）
2. 方向键在候选列表内移动，不移动编辑器光标
3. 数字键选择候选，提交后只插入一次
4. Esc 取消组合，正文不变
5. 长拼音预编辑不越出编辑区，候选窗跟随光标
6. 选中文本后输入，提交内容替换选区
7. 连续输入两个词，中间无重复、无丢字
8. 在行首、行尾、软换行处各验证一次候选窗位置
9. 切换中英文（Ctrl+Space）后直接输入英文，字符不被吞
10. 组合中点击其他位置或切换标签，不产生残留预编辑

## 键位与交互回归

- Ctrl+B/I/K、Ctrl+1–6、Ctrl+Shift+B/N、Ctrl+Q
- 标题/引用源码标记淡显、打字机模式、专注模式、选区浮动格式条

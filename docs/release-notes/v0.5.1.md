# MDOxide v0.5.1

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

未签名构建，Windows 首次运行可能被 SmartScreen 拦截；请用 `checksums.txt` 核对 SHA256。

Unsigned builds — SmartScreen may block the first launch. Verify with `checksums.txt`.

| 平台 / Platform | 架构 / Arch | 文件 / File | 安装 / Install |
|---|---|---|---|
| Fedora / RHEL / openSUSE | x86_64 | `mdoxide-editor-0.5.1-1.x86_64.rpm` | `sudo dnf install ./<file>.rpm` |
| Fedora / RHEL / openSUSE | aarch64 | `mdoxide-editor-0.5.1-1.aarch64.rpm` | `sudo dnf install ./<file>.rpm` |
| Debian / Ubuntu | amd64 | `mdoxide-editor_0.5.1-1_amd64.deb` | `sudo apt install ./<file>.deb` |
| Debian / Ubuntu | arm64 | `mdoxide-editor_0.5.1-1_arm64.deb` | `sudo apt install ./<file>.deb` |
| Windows | x64 | `MDOxide-0.5.1-x64-setup.exe` | 运行安装包；SmartScreen 选「更多信息 → 仍要运行」 |
| Windows | ARM64 | `MDOxide-0.5.1-arm64-setup.exe` | 同上；与 x64 安装可并存 |

校验 / Verify：

```bash
sha256sum -c checksums.txt
```

## 本版亮点 / Highlights

- **源码编辑器右键菜单**：复制、剪切、粘贴、全选；多光标选区同样适用
- **预览块级右键菜单**：可编辑块支持复制/剪切/粘贴/全选，非编辑块可“复制本段”
- **预览整篇复制**：右键菜单新增“复制全部（纯文本）”和“复制为 Markdown”
- **本地化**：中英文翻译键增至 1006

## 说明 / Notes

- 预览仍按块渲染与编辑，跨段拖选暂不支持；“复制全部”可用于整篇复制
- 纯文本投影只在点击菜单时计算，不会重新引入每帧全文扫描

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

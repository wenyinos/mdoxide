# MDOxide v0.3.2

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

未签名构建，Windows 首次运行可能被 SmartScreen 拦截；请用 `checksums.txt` 核对 SHA256。

Unsigned builds — SmartScreen may block the first launch. Verify with `checksums.txt`.

| 平台 / Platform | 架构 / Arch | 文件 / File | 安装 / Install |
|---|---|---|---|
| Fedora / RHEL / openSUSE | x86_64 | `mdoxide-editor-0.3.2-1.x86_64.rpm` | `sudo dnf install ./<file>.rpm` |
| Fedora / RHEL / openSUSE | aarch64 | `mdoxide-editor-0.3.2-1.aarch64.rpm` | `sudo dnf install ./<file>.rpm` |
| Debian / Ubuntu | amd64 | `mdoxide-editor_0.3.2-1_amd64.deb` | `sudo apt install ./<file>.deb` |
| Debian / Ubuntu | arm64 | `mdoxide-editor_0.3.2-1_arm64.deb` | `sudo apt install ./<file>.deb` |
| Windows | x64 | `MDOxide-0.3.2-x64-setup.exe` | 运行安装包；SmartScreen 选「更多信息 → 仍要运行」 |
| Windows | ARM64 | `MDOxide-0.3.2-arm64-setup.exe` | 同上；与 x64 安装可并存 |

校验 / Verify：

```bash
sha256sum -c checksums.txt
```

## 本版亮点 / Highlights

- **六个发布产物**：Linux RPM/DEB 各提供 x86_64 与 aarch64/arm64，Windows 提供 x64 与 ARM64 安装包
- **修复标题栏重叠**：视图模式分段切换不再重复占用布局空间，字数统计与模式切换不再叠加，两个控件均可正常点击
- **恢复专注模式按钮**：标题栏新增专注（Zen）切换按钮，与 F11、菜单项状态同步；专注模式仍保留顶部标签页
- **ARM64 独立安装**：Windows ARM64 使用独立安装目录、开始菜单与卸载注册表项，可与 x64 版本并存

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

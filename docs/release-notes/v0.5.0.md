# MDOxide v0.5.0

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

未签名构建，Windows 首次运行可能被 SmartScreen 拦截；请用 `checksums.txt` 核对 SHA256。

Unsigned builds — SmartScreen may block the first launch. Verify with `checksums.txt`.

## 本版亮点 / Highlights

- **修订号成为唯一失效依据**：Raw 编辑器同步、撤销快照、AST、Mermaid 小地图缓存都按 `content_version` 失效，滚动与移动光标不再触发全文哈希
- **外部修改只有一个入口**：`replace_from_disk` 同步更新正文、编码/BOM、磁盘锚点与修订号；修复 5 MB 以上等长外部修改被旧缓冲覆盖、非 UTF-8 重载损坏
- **启动恢复收敛**：只保留 session.json 一条路径；恢复全部失败时保留现有标签；配置只加载一次
- **崩溃恢复增量写入**：按标签修订号只写变化过的正文，未修改文档不再每 5 秒重写全文
- **缓存有预算**：AST 缓存增加 64 MB 字节预算；关闭标签只移除该文档，不再清空其他文档缓存
- **资源与安全边界**：工作区索引可取消；代码执行 2 MB 输出上限、独立进程组与进程树终止、0600 临时文件；HTML 活动内容默认关闭；终端布局默认不自动加载
- **统一大小策略**：1 MB / 5 MB / 10 MB 阈值集中到 `DocumentSizePolicy`

## 兼容性说明 / Compatibility

- `Tab.content` 仍作为受控只读快照保留，所有正文变更必须经过修订号 API；完整的 `Document`/`EditorSession` 物理拆分将在后续版本继续增量进行
- 旧的 `settings.last_open_tabs` 不再参与启动恢复；如 session.json 缺失，启动会显示空白文档

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

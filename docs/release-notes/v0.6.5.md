# MDOxide v0.6.5

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

## 本版亮点 / Highlights

- **正文所有权收敛**：新增 `Document`，统一持有正文、原正文、路径、编码/BOM/原字节、撤销历史、修订号与修订缓存；`Tab` 只保留 ID、类型与视图元数据，通过 `Deref` 访问文档
- **状态层拆分**：`state.rs` 从 8246 行降至 4841 行，拆出 `document.rs`、`editor_session.rs`、`ui_state.rs`、`workspace.rs`
- **构造路径统一**：标签创建、文件加载与会话恢复全部改为构造 `Document`，补齐 `had_bom`/`original_bytes`
- **稳定性清理**：移除 `Tab` 尾部悬空文档注释，消除由此触发的错误类型恢复与后续字段类型误推断

## 说明 / Notes

- 本版为内部架构版本，无用户可见功能变更
- `Document.content` 仍为 `String`，Raw 编辑器 `TextBuffer` 的 Rope 尚未合并为单一正文；跨模块正文写入尚未收敛到统一文档 API
- 预览仍按块选择，不支持跨段拖选；“复制全部 / 复制为 Markdown”可复制整篇

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

# MDOxide v0.8.0

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

未签名构建，Windows 首次运行可能被 SmartScreen 拦截；请用 `checksums.txt` 核对 SHA256。

Unsigned builds — SmartScreen may block the first launch. Verify with `checksums.txt`.

## 本版亮点 / Highlights

- **Markdown 富块**：`<details>/<summary>` 折叠、`<div align>` 对齐、`<kbd>/<sup>/<sub>/<img>` 内联标签、`<br>` 换行
- **Mermaid 第二波**：点击图表打开缩放/平移弹窗；`sequenceDiagram autonumber`、`%% @pos`、`fa:` 前缀、`linkStyle` 多索引、fit-to-pane
- **完整 gitGraph**：commit `tag`/`type`、branch `order`、`cherry-pick`、LR/TB 布局与 tag 徽章
- **渲染视图键盘导航**：方向键在标题/段落块间移动，Enter 进入编辑；可选预览锁定
- **字体体系**：编辑器/渲染/终端各自选择字体，支持自定义系统字体；终端自动注册 Nerd Font/Powerline 字形回退
- **设置与工作区**：设置搜索按行过滤并直接显示控件；Stats 运行时模块；文件树活动行/目录图标/缩进引导线
- **数据安全**：编码切换确认、有损编码保存拒绝、UTF-16 BOM、CRLF 保持、退出保存全部标签、损坏配置备份
- **Linux 体验**：中键主选区粘贴（150ms 防抖、单次撤销）、可选原生系统标题栏

## 说明 / Notes

- `Document.content` 仍为 `String`，Raw 编辑器 `TextBuffer` 的 Rope 尚未合并为唯一正文
- 预览仍按块选择，不支持跨段拖选；“复制全部 / 复制为 Markdown”可复制整篇
- 原生系统标题栏仅在 Linux 提供，切换后需重启

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

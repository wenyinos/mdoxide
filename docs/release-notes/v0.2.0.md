# MDOxide v0.2.0

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

未签名构建，Windows 首次运行可能被 SmartScreen 拦截；请用 `checksums.txt` 核对 SHA256。

Unsigned builds — SmartScreen may block the first launch. Verify with `checksums.txt`.

| 平台 / Platform | 文件 / File | 安装 / Install |
|---|---|---|
| Fedora / RHEL / openSUSE | `mdoxide-editor-0.2.0-1.x86_64.rpm` | `sudo dnf install ./<file>.rpm` |
| Debian / Ubuntu | `mdoxide-editor_0.2.0-1_amd64.deb` | `sudo apt install ./<file>.deb` |
| Windows x64 | `MDOxide-0.2.0-setup.exe` | 运行安装包；SmartScreen 选「更多信息 → 仍要运行」 |

校验 / Verify：

```bash
sha256sum -c checksums.txt
```

## 本版亮点 / Highlights

- **Duskfox Blurred 主题**：色号直接读取自 Zed 的 `nvim-nightfox` 扩展（`Duskfox - blurred`），半透明表面，配合 KWin 窗口模糊规则可获得接近 Zed 的模糊效果
- **全新应用图标**：duskfox 配色、透明圆角，提供 16–1024 全尺寸 PNG 与 Windows 多尺寸 ICO
- **界面汉化补全**：中英文 989 个翻译键完全对齐；命令名、命令分类、面板、错误提示不再残留英文
- **默认跟随系统语言**：用户显式选择语言后才固定该选择
- **更舒适的排版**：默认字号 15px、1.5 倍行高，中文界面优先使用思源黑体
- **导出与交互**：RaTeX 数学公式、Mermaid、HTML/PDF 导出；fcitx5 IME 已在 Wayland 真机验证
- **Windows 安装包修复**：NSIS 路径与版本号解析正确

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

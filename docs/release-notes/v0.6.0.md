# MDOxide v0.6.0

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

## 本版亮点 / Highlights

- **稳定工具链**：`rust-toolchain.toml` 与 CI/Release 切换为 stable Rust，不再固定 1.92
- **耐久原子写**：会话、逐标签恢复和自动保存统一走 `write_atomic`（临时文件 + fsync + rename + 目录 fsync）
- **配置备份保留**：保存前把上一版写入 `config.json.bak`，再原子替换 `config.json`
- **恢复写入后台化**：崩溃快照由单写线程序列化；UI 线程只提交变化内容，干净标签哈希按修订号缓存
- **索引事件合并**：工作区索引增加 400 ms 静默期，同一时刻最多一个扫描线程
- **Raw 编辑操作级上报**：`TextBuffer` 记录 insert/delete，编辑器重放到 `Tab.content`；不再每键整篇 `to_string` + 全文 diff，也不再每帧准备撤销快照

## 说明 / Notes

- `Tab.content` 仍作为受控快照保留；`Document`/`EditorSession` 单一 Rope 的迁移留待后续版本
- 预览仍按块选择，不支持跨段拖选；“复制全部 / 复制为 Markdown”可复制整篇

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

# MDOxide v0.8.5

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

## 本版亮点 / Highlights

来自 MarkText `0.24.0-dev` 的特性移植（行为级重写，非代码照搬）：

- **脚注**：正文引用按首次出现顺序编号，文末定义显示 `[n]` 与缩进内容
- **标题折叠**：标题左侧 chevron 折叠章节，支持嵌套；View 菜单提供「折叠全部 / 展开全部标题」
- **Slash 快速插入**：段落输入 `/` 或 `、` 弹出 12 类块候选（标题、列表、任务、引用、代码块、表格、公式、Mermaid、分隔线），↑/↓ 选择，Enter 或点击应用
- **Emoji 补全**：段落输入 `:prefix` 弹出短代码列表，选择后写入 `:name:`
- **表格棋盘插入**：格式菜单「插入表格」弹出 6×8 悬浮网格
- **图片缩放**：图片右下角拖拽手柄调整宽度，写回 `<img src alt width>`；手写 `<img width="N">` 按指定宽度渲染
- **标题锚点**：标题左侧 `#` 按钮复制 GitHub 风格标题链接
- **链接工具**：弹窗新增「取消链接」，保留文本并剥离 `[text](url)` / 裸链接语法
- **其他**：渲染右键「复制为 HTML」、图片悬停工具（复制路径/打开所在文件夹）、设置搜索纳入键盘快捷键、上标与描述列表渲染分支

## 说明 / Notes

- 描述列表与上标解析扩展默认关闭，与 MarkText 的默认偏好一致
- 折叠与锚点均为视图状态，不改写文档正文与撤销历史
- `Document.content` 仍为 `String`，Raw 编辑器 `TextBuffer` 的 Rope 尚未合并为唯一正文
- 预览仍按块选择，不支持跨段拖选；“复制全部 / 复制为 Markdown / 复制为 HTML”可导出整篇

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

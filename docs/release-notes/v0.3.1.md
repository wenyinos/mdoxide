# MDOxide v0.3.1

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

未签名构建，Windows 首次运行可能被 SmartScreen 拦截；请用 `checksums.txt` 核对 SHA256。

Unsigned builds — SmartScreen may block the first launch. Verify with `checksums.txt`.

| 平台 / Platform | 文件 / File | 安装 / Install |
|---|---|---|
| Fedora / RHEL / openSUSE | `mdoxide-editor-0.3.1-1.x86_64.rpm` | `sudo dnf install ./<file>.rpm` |
| Debian / Ubuntu | `mdoxide-editor_0.3.1-1_amd64.deb` | `sudo apt install ./<file>.deb` |
| Windows x64 | `MDOxide-0.3.1-setup.exe` | 运行安装包；SmartScreen 选「更多信息 → 仍要运行」 |

校验 / Verify：

```bash
sha256sum -c checksums.txt
```

## 本版亮点 / Highlights

- **标题栏快捷控件回归**：在 MarkText 汉堡菜单与居中标题之外，恢复视图模式分段切换（源码 / 分屏 / 渲染）和设置按钮
- **右侧布局重排**：文档统计 → 视图切换 → 设置 → 最小化 / 最大化 / 关闭；窄窗口仍优先收起统计
- **禅模式保留标签页**：F11 无干扰模式现在只隐藏侧栏与状态栏，顶部标签页继续可用，写作中可随时切换文档
- **专注模式不变**：仍只淡化非当前编辑块，标签栏与标题栏保持可见

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

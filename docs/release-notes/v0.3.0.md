# MDOxide v0.3.0

原生 Rust 写成的所见即所得 Markdown 编辑器。无 WebView、无 Electron、无 JavaScript 运行时。

## 下载 / Downloads

未签名构建，Windows 首次运行可能被 SmartScreen 拦截；请用 `checksums.txt` 核对 SHA256。

Unsigned builds — SmartScreen may block the first launch. Verify with `checksums.txt`.

| 平台 / Platform | 文件 / File | 安装 / Install |
|---|---|---|
| Fedora / RHEL / openSUSE | `mdoxide-editor-0.3.0-1.x86_64.rpm` | `sudo dnf install ./<file>.rpm` |
| Debian / Ubuntu | `mdoxide-editor_0.3.0-1_amd64.deb` | `sudo apt install ./<file>.deb` |
| Windows x64 | `MDOxide-0.3.0-setup.exe` | 运行安装包；SmartScreen 选「更多信息 → 仍要运行」 |

校验 / Verify：

```bash
sha256sum -c checksums.txt
```

## 本版亮点 / Highlights

- **界面按 MarkText 复刻**：32px 无边框标题栏，左侧汉堡应用菜单（文件 / 编辑 / 格式 / 视图 / 工具 / 帮助），中间显示目录、文件名与未保存圆点，右侧显示文档统计和窗口按钮
- **移除 Ferrite 遗留元素**：ribbon 工具栏、底部状态栏、右侧侧栏开关条全部移除；快捷键、浮动格式条与命令面板仍然可用，通知改为底部居中浮动提示
- **MarkText 标签栏**：28px 高、活动标签带 2px 主题色下划线；未保存圆点与悬停关闭按钮共用一个位置，长标题自动省略
- **表格不再裁剪文字**：列宽与行高的测量、绘制、点击定位统一使用同一套富文本布局；价格、URL 等不可断词允许任意断行；列宽总和超限时整体等比缩放
- **更舒适的行距**：正文 1.5 → 1.6 倍（15px 字号对应 24px 行高），表格单元格内边距同步加大，行高按实际富文本高度计算
- **中文统计更准确**：标题栏对 CJK 文档显示字符数，英文文档显示词数
- **本地化更新**：中英文翻译键由 989 增至 996，覆盖新增菜单与视图项

## 已知限制 / Known limitations

- PDF v1：Mermaid 输出为代码块、图片为占位符、无 bidi 重排
- 仅支持 Linux 与 Windows，不提供 macOS 构建
- 背景透明效果依赖桌面合成器；不开窗口模糊时表现为半透明

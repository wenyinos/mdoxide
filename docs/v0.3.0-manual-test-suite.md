**How to use:**

1. Work top to bottom; check each box as you pass it.
2. Open **`test_md/rendered-edit-session-test.md`** for rendered-mode click-to-edit (Tasks 94–105).
3. Run the platform matrix in [`v0.3.0-regression-matrix.md`](./technical/platform/v0.3.0-regression-matrix.md) on your OS — it covers egui 0.34 deltas not repeated here.
4. For older features unchanged by v0.3.0, spot-check [`v0.2.8-manual-test-suite.md`](./v0.2.8-manual-test-suite.md) §12 (regressions).

**Legend:** `[ ]` = not tested · `[x]` = passed · `[!]` = failed (log in **Issues Found**)
